# PokéSurvivor sprites

Pokémon Mystery Dungeon–style sprite sheets used by a modified copy of the
[PokéSurvivor](https://github.com/JPTER78/pokesurvivor) fan game, served with
GitHub Pages so the game can load them (`assets/pokemon/{dex}/{Anim}.png`,
shiny versions in `s/`).
